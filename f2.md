# r0t4 - Two commits, one push

Continue in the same repository after completing r0t3.

Copy these five files into your repository folder beside README.md.
Replace the existing f1.txt and f2.md when asked. Keep README.md unchanged.

1. Commit only f3.txt, f4.txt and f5.txt with this exact summary:
   my new source code additions
   Do not push yet.

2. Commit the remaining changes in f1.txt and f2.md with this exact summary:
   my source code has been updated

3. Push both commits together.

Clue: The checkboxes beside changed files in GitHub Desktop control which files
are included in a commit. Check History to see your two separate commits.
